🚀 What's New

SoftAim System: Advanced aim assistance with natural micro-adjustments, line-of-sight checking, and automatic weapon switching capabilities.

cl_rDrive System: Revolutionary randomized SOCD (Simultaneous Opposite Cardinal Directions) input clearing system that provides unpredictable input behavior for competitive play.

🎯 SoftAim System

Advanced aim assistance with target prioritization, line-of-sight validation, distance-based strength scaling, and smooth natural movement. Only activates when attacking.

cl_softaim 1 cl_softaim_strength 1.0 cl_softaim_maxdist 512 cl_softaim_fov 90 cl_softaim_smooth 0.3

🎲 cl_rDrive - Randomized SOCD

Advanced randomized input clearing system. Unlike deterministic cl_iDrive, this randomly chooses which input to clear with configurable timing.

cl_rDrive 1 cl_rDrive_ms 5 cl_rDrive_pairs "forward,back;left,right"

⚡ cl_iDrive - Deterministic SOCD

Traditional SOCD cleaning where the most recently pressed key takes priority. Predictable and consistent behavior.

cl_iDrive 1

🔧 Flexible Configuration

Highly configurable systems with support for custom key pairs, timing adjustments, and various input combinations.

Supported Keys: forward, back, left, right, moveleft, moveright, up, down, lookup, lookdown, attack, attack2, jump, use, speed, strafe

📖 Configuration Guide

SoftAim Configuration

// Basic SoftAim setup cl_softaim 1 // Enable SoftAim cl_softaim_strength 1.0 // Assistance strength (0.5-2.0) cl_softaim_maxdist 512 // Maximum targeting distance cl_softaim_fov 90 // Field of view for targeting cl_softaim_smooth 0.3 // Smoothing factor (0.01-1.0) cl_softaim_autoswitch 1 // Auto weapon switching (LG/SG) cl_softaim_lg_range 350 // Lightning gun optimal range

SoftAim Features

  • Smart Target Selection: Prioritizes closest enemies within FOV with line-of-sight validation
  • Distance Scaling: Assistance strength automatically scales based on target distance
  • Attack-Only Activation: Only works when firing to maintain natural movement
  • Auto Weapon Switch: Intelligently switches between Lightning Gun and Shotgun based on range
  • Smooth Interpolation: Natural feeling adjustments that blend with player input

cl_rDrive Configuration

// Randomized SOCD setup cl_rDrive 1 // Enable randomized SOCD cl_rDrive_ms 5 // Max delay in milliseconds cl_rDrive_pairs "forward,back;left,right" // Configure key pairs // Advanced configuration cl_rDrive_pairs "forward,back;left,right;attack,attack2;lookup,lookdown"
⚠️ Important: Only enable one SOCD system at a time. Use either cl_iDrive OR cl_rDrive, not both simultaneously.

🔄 How cl_rDrive Works

  1. Conflict Detection: When both keys in a configured pair are pressed simultaneously
  2. Random Selection: The system randomly chooses which key to clear (50/50 chance)
  3. Random Timing: A random delay (0 to cl_rDrive_ms milliseconds) is applied
  4. Input Clearing: The selected key's input is cleared after the delay
  5. State Reset: When both keys are released, the system resets

📊 Comparison: cl_iDrive vs cl_rDrive

Feature cl_iDrive cl_rDrive
Clearing Logic Deterministic (newest key wins) Random selection
Timing Immediate Random delay (0-N ms)
Configuration Fixed key pairs User-configurable pairs
