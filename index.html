🚀 What's New

cl_rDrive System: Revolutionary randomized SOCD (Simultaneous Opposite Cardinal Directions) input clearing system that provides unpredictable input behavior for competitive play.

🎯 SoftAim System

Subtle aim assistance that helps with micro-adjustments when firing. Natural feeling assistance that doesn't feel like a traditional aimbot.

cl_softaim 1 cl_softaim_strength 1.0 cl_softaim_maxdist 512

🎲 cl_rDrive - Randomized SOCD System

Randomized SOCD cleaning system that works identically to cl_iDrive but applies input resolution with configurable random delay. Makes SOCD cleaning timing less predictable and more human-like.

cl_rDrive 1 cl_rDrive_min_ms 0.01 cl_rDrive_max_ms 5

⚡ cl_iDrive - Deterministic SOCD

Traditional SOCD cleaning where the most recently pressed key takes priority. Predictable and consistent behavior.

cl_iDrive 1

🔧 Flexible Configuration

Highly configurable systems with support for custom key pairs, timing adjustments, and various input combinations.

Note: cl_rDrive specifically targets left/right strafe conflicts for randomized SOCD cleaning with microsecond precision timing.

📖 Configuration Guide

SoftAim Configuration

// Basic SoftAim setup cl_softaim 1 // Enable SoftAim cl_softaim_strength 1.0 // Assistance strength (0.5-2.0) cl_softaim_maxdist 512 // Maximum targeting distance cl_softaim_fov 90 // Field of view for targeting cl_softaim_smooth 0.3 // Smoothing factor cl_softaim_autoswitch 0 // Auto weapon switching (experimental)

cl_rDrive Configuration

// Basic cl_rDrive setup cl_rDrive 1 // Enable randomized SOCD (0=off, 1=on) cl_rDrive_min_ms 0.01 // Minimum delay in milliseconds cl_rDrive_max_ms 5 // Maximum delay in milliseconds // Very fast random delay (0.01ms to 0.02ms) cl_rDrive 1 cl_rDrive_min_ms 0.01 cl_rDrive_max_ms 0.02 // Moderate random delay (1ms to 5ms) cl_rDrive 1 cl_rDrive_min_ms 1 cl_rDrive_max_ms 5
⚠️ Important: Only enable one SOCD system at a time. Use either cl_iDrive OR cl_rDrive, not both simultaneously.

🔄 How cl_rDrive Works

  1. Detects Conflicts: When opposite strafe keys are pressed simultaneously:
    • left + right (when +strafe is active)
    • moveleft + moveright
  2. Random Delay: Applies random delay between cl_rDrive_min_ms and cl_rDrive_max_ms
  3. Clear Older Input: After delay expires, clears the OLDER input based on key press timing (last key pressed wins - same logic as cl_iDrive)
  4. High Precision: Uses Sys_DoubleTime() for microsecond-accurate timing
  5. State Reset: Conflict state resets when both keys are released

📊 Comparison: cl_iDrive vs cl_rDrive

Feature cl_iDrive cl_rDrive
SOCD Method Last key wins Last key wins
Delay Instant (0ms) Random (min to max ms)
Timing Deterministic Randomized
Precision Frame-based Microsecond-based (Sys_DoubleTime)
Affected Inputs All directional Left/Right strafe only

🎯 Use Cases

  • Natural Input Patterns: Provides SOCD cleaning with variable timing for more natural input patterns
  • Non-Deterministic Resolution: Useful for players who want non-deterministic input resolution
  • Strafe-Only Conflicts: Only affects left/right strafe conflicts
  • Flexible Timing: Can be configured for very short delays (sub-millisecond) or longer delays

⚙️ Technical Details

  • Implementation: src/cl_input.c
  • Timing System: Uses Sys_DoubleTime() for high-precision timing
  • Conflict Detection: Happens per-frame in CL_BaseMove()
  • Conflict Tracking: Only one conflict can be tracked at a time (strafe or moveleft/moveright)
  • State Management: Conflict state resets when both keys are released

📝 Important Notes

  • Mutual Exclusivity: Cannot be used simultaneously with cl_iDrive (use one or the other)
  • Movement Scope: Does not affect forward/back movement, only left/right strafe
  • Randomization: Delay timing is randomized on each new conflict detection
